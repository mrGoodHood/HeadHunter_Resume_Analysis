# Анализ резюме HeadHunter

Учебный проект по исследованию, преобразованию и очистке данных резюме с HeadHunter.

## Цель проекта

Подготовить данные к дальнейшему анализу и исследовать связь желаемой заработной платы с образованием, возрастом, опытом работы, городом и предпочтениями соискателей.

Проект включает разведывательный анализ данных. Обучение модели машинного обучения не входит в его задачи.

## Данные

Исходный датасет содержит **44 744 резюме и 12 столбцов**. Для пересчёта зарплат в рубли используется таблица курсов валют за период с 29 декабря 2017 года по 5 декабря 2019 года.

Оба файла предоставлены в материалах курса. Данные хранятся отдельно и не включены в Git-репозиторий.

**[Скачать данные](https://drive.google.com/drive/folders/1OGh-rjkNV1Ci-C-m3-OeZqI7Vs9NGy8F?hl=ru)**

Перед запуском скачайте файлы и поместите их в папку `data/`:

- `dst-3.0_16_1_hh_database.csv`
- `ExchangeRates.csv`

Имя основного CSV должно совпадать с именем, указанным в ячейке загрузки данных в ноутбуке.

Анализ относится к исторической учебной выборке и не описывает текущее состояние рынка труда. В резюме указана желаемая, а не фактически получаемая зарплата.

## Этапы работы

### 1. Исследование структуры данных

Изучены состав таблицы, типы признаков, пропуски и описательная статистика.

### 2. Преобразование признаков

- Выделены уровень образования, пол и возраст.
- Опыт работы переведён в месяцы.
- Созданы категории городов.
- Выделены признаки готовности к переезду и командировкам.
- Варианты занятости и графика представлены отдельными булевыми признаками.
- Желаемая зарплата пересчитана в рубли по курсу на дату обновления резюме с учётом пропорции валюты.

### 3. Разведывательный анализ

Исследованы распределения возраста, опыта работы и желаемой зарплаты.

Построены визуализации для изучения связи зарплатных ожиданий со следующими признаками:

- образование;
- город проживания;
- возраст;
- готовность к переезду;
- готовность к командировкам.

Также исследовано соответствие опыта работы возрасту соискателей.

Дополнительно рассмотрены:

- готовность к переезду в разных возрастных группах;
- различия зарплатных ожиданий в зависимости от выбора удалённой работы.

### 4. Очистка данных

| Этап | Результат |
|---|---|
| Удаление полных дубликатов | Удалена 161 строка |
| Обработка пропусков в месте работы и должности | Удалены 2 строки |
| Обработка пропусков в опыте работы | Пропуски заполнены медианой 100 месяцев |
| Удаление зарплат ниже 1 тыс. и выше 1 млн рублей | Удалены 89 строк |
| Удаление резюме, в которых стаж превышает возраст | Удалены 7 строк |
| Поиск выбросов возраста в логарифмической шкале | Удалены 3 строки |

Для поиска выбросов возраста использованы границы в три стандартных отклонения ниже среднего и четыре выше среднего логарифма возраста.

После очистки осталось **44 482 резюме и 23 признака**. Пропуски и полные дубликаты отсутствуют. Всего удалено **262 строки**.

## Основные результаты

Результаты разведывательного анализа получены до этапа очистки. Для сравнений по образованию и городам использованы резюме с желаемой зарплатой строго менее 1 млн рублей.

| Показатель | Результат |
|---|---|
| Медианная желаемая зарплата по всей выборке | 59 019 руб. |
| Медианная зарплата при высшем образовании | 60 000 руб. |
| При неоконченном высшем образовании | 50 000 руб. |
| При среднем и среднем специальном образовании | 40 000 руб. |
| Медианная зарплата в Москве | 85 000 руб. |
| В Санкт-Петербурге | 60 000 руб. |
| В городах-миллионниках и других городах | 40 000 руб. |
| Медианная зарплата готовых к переезду и командировкам | Около 65 849 руб. |
| Наибольшая доля готовых к переезду | 38,46% в группе от 25 до 34 лет |
| Медианная зарплата при указании удалённой работы | 60 000 руб. |
| Медианная зарплата без указания удалённой работы | 55 000 руб. |

Образование, город и предпочтения соискателей связаны с зарплатными ожиданиями. Однако обнаруженные связи не доказывают причинного влияния. Группы могут различаться по профессии, опыту и другим характеристикам.

## Запуск проекта

### 1. Подготовка проекта

Скачайте или клонируйте репозиторий. Откройте папку проекта в VS Code.

Для работы с ноутбуком установите расширения **Python** и **Jupyter**, если они ещё не установлены.

### 2. Создание окружения

В терминале корня проекта выполните:

```powershell
python -m venv .venv
```

### 3. Установка зависимостей

Для Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. Подготовка данных

Скачайте основной датасет и таблицу курсов валют по ссылке в разделе «Данные». Поместите оба файла в папку `data/`.

Проверьте, что имена файлов соответствуют путям в ячейках `pd.read_csv()`.

### 5. Выполнение ноутбука

Откройте `analysis.ipynb` и выберите ядро Python из окружения `.venv`.

Выполните **Restart Kernel**, затем **Run All**. Ячейки необходимо запускать последовательно, начиная с загрузки исходных данных.

Ожидаемая итоговая проверка:

```text
Размер таблицы: (44482, 23)
Пропусков: 0
Полных дубликатов: 0
```

## Ограничения анализа

- Выборка содержит исторические данные и не отражает текущие зарплаты.
- Зарплатные ожидания могут отличаться от реальных предложений работодателей.
- Медианы малочисленных групп могут определяться единичными наблюдениями.
- Статистический выброс не обязательно является ошибкой. Очистка выполнена по условиям учебного проекта.
- Наблюдаемые связи между признаками не означают причинной зависимости.
